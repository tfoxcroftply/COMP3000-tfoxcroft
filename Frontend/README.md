\# Installation instructions (Windows)

\###  Requirements

&#x20;- NodeJS (\[Node.js — Download Node.js®](https://nodejs.org/en/download/current)) (Select "Add to PATH" during installation)

&#x20;- Bonjour Print Services (\[Download Bonjour Print Services for Windows v2.0.2 - Apple Support](https://support.apple.com/en-us/106380))



\### Usage

&#x20;1. Clone repository into a folder

&#x20;2. Open CMD from folder

&#x20;3. Run `cd .\Frontend` 

&#x20;3. Run `npm install` 

&#x20;4. Run `npm run dev`

&#x20;5. Allow local network access
